## Baseline

- Global dark canvas: `#0B1114`; Community deep teal is scoped to the Community module.
- Light theme: off-white global canvas, neutral/white surfaces.
- Core identity: deep teal, forest, signal lime, cool charcoal; accessible semantic colours.
- Module accents: Community forest; Learning indigo; Recruitment blue; Payments plum; info slate.
- Inter UI; JetBrains Mono technical; Noto Sans Devanagari fallback.
- WCAG 2.2 AA; breakpoints 640, 768, 1024, 1280, 1536.

## Matte Black reference (scoped)

Canvas `#0B0D0C`, surface `#171A18`, elevated `#222724`, border `#303631`, forest `#156152`, lime `#C7FE53`, experimental violet `#A78BFA`. Intended for analytical dashboards; not global palette replacement.

## Owner clarification — 26 Nov 2026

Creative exploration remains open: test new hues, Pantone-referenced studies, gradients, layout, typography, patterns and motion. The system provides coherence, not rigid aesthetic limits. Current pattern work must be transparent overlays and must not repaint existing backgrounds.

## History policy

Preserve original tokens and dated alternatives; record new token changes with source, rationale, contrast/accessibility validation and module/theme scope.

## Design psychology guardrail — 27 Nov 2026

No new palette or theme is approved by this note. Existing tokens provide coherence, not a restriction on creative exploration. Colour, contrast, glow, gradients and surface/material treatments must be chosen for hierarchy, legibility, emotional tone and semantic accuracy—not trend alone.

- Reserve high-intensity accents for meaningful attention or state; do not make every element compete.
- Never rely on hue alone for status, trust, verification or error.
- Glass/translucent surfaces require readable contrast, stable boundaries and a clear layering purpose; do not use blur merely as a premium signal.
- Dark OLED-like themes are contextual choices, not universal defaults. Test content readability, glare/contrast and user task suitability.
- Maintain approved type roles (Inter UI, JetBrains Mono for purposeful technical metadata, Noto Sans Devanagari fallback) unless a tested proposal justifies change.
- Any new colour/token proposal must record scope, rationale, semantic role, contrast tests, light/dark behavior and decision status.
