## Rules

Use original supplied source files as authority for historical wording. Do not infer unavailable discussion content from summaries. Mark source gaps and conflicts explicitly; add a reconciliation note only when evidence is available.

## Known gaps

- Some decision descriptions (notably DEC-050–053 in one changelog context) were not recovered in the source set.
- Separate discussion transcripts outside the available 24–26 Nov source package were not available for independent verification.
- Repository implementation state, current production status and actual package installation were not established by the documentation archive.
- Historical member counts and lab costs are snapshots/planning figures, not current verified data.

## Reconciliation method

For each new source: identify date and version, retain the exact original, compare with current canonical documents, document additions/deletions/contradictions, map IDs, update source index and checksums, and keep unresolved items visible.
