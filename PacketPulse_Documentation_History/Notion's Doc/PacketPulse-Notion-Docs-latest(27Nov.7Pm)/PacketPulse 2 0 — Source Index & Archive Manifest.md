## Archive structure

The prepared documentation-history archive contains 205 files grouped into:

- `current/`: canonical five-document set, current changelog, update summaries, handoffs, prototype review register and technical source register.
- `governance/`: project evolution/memory, master changelog, decision register, token history, historical gaps and source index.
- `discussions/`: dated discussion and handoff records.
- `history/releases/`: immutable dated release snapshots.
- `history/source-packages/`: original ZIP packages.
- `design/`: design assets and references.

## Integrity and provenance

The source package retains the exact dated files. Keep release packages read-only; create new dated releases rather than replacing older ones. Check manifests/checksums when transferring or updating the archive.

## Git / distribution

The documentation repository was prepared as a separate companion repo, distinct from the product repo. The intended public destination is `kartik-binzade/packetpulse-community-2.0`; publishing status must be independently verified.
