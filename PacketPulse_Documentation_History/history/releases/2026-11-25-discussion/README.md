## Owner-directed principles

- Be open, creative and experimental. Do not prematurely reject useful ideas.
- Keep whitespace and emotional experience central to UX quality.
- Preserve Signal Grove while supporting Editorial and Analytical workspaces.
- Matte Black is the preferred analytical dashboard reference; retain a light counterpart.
- Use microanimations purposefully and honour reduced-motion preferences.
- Tailwind CSS v4 is the styling standard: CDN for prototyping only; compiled build for production.
- Candidate libraries are references and adoption candidates, not claims of installed dependencies.

## Implementation status

These files are design and product specifications. They do not prove that a component, library, route or feature is implemented. Audit the repository before package changes or implementation claims.
