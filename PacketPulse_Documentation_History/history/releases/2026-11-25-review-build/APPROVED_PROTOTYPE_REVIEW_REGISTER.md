## Non-negotiable production gates

Prototype approval does not waive:

- Repository and dependency audit (DEV-01 to DEV-11).
- Licence and attribution verification for libraries and media assets.
- Server-side access control and exact profile field-visibility enforcement.
- Secure file upload, malware scanning, storage permission and link expiry.
- OAuth provider configuration, account-linking protections and recovery checks.
- Privacy, consent, data retention, age and legal counsel review.
- Payment provider verification and sandbox/production separation.
- WCAG 2.2 AA validation, real assistive technology testing and reduced-motion support.
- Production monitoring, rollback, auditability and explicit go-live approval.
