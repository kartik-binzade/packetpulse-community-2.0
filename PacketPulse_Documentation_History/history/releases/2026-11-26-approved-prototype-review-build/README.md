## Owner direction

Be open, creative and experimental. Design principles are guidance, not rigid visual constraints. Explore patterns, colour, layout, type, media and motion. Brand patterns are transparent overlays and do not change existing backgrounds. Everything marked Approved Prototype must appear in the next review build or be represented by an explicit mock/sandbox state if a real provider/backend is not configured. The review outcome can be Retain, Refine, Restrict or Remove.
